# Job Offer Generator — Top Bliss Solutions Inc.

A standalone web app for generating job offer letters as `.docx` files on company letterhead.

## How to use
Open the site, fill in the hire details, click **Generate & Download**. The offer letter downloads instantly.

## What's included automatically
- 7-Day Culture Fit Test stage
- 30-Day Skills Test stage
- 6-Month Probationary Period with AI-generated 30-60-90 day phases
- Company letterhead (header + footer)
- Salary schedule (1–15 → 25th; 16–30 → 10th of following month)

## Deployment
Connected to Netlify. Any push to `main` branch automatically redeploys the site.

## To make changes
1. Edit `index.html`
2. Commit and push to GitHub
3. Netlify redeploys in ~30 seconds — no manual upload needed
